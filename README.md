# 555 Timer Contact Alarm PCB

## Overview

This project is a simple contact alarm circuit designed using the NE555 Timer IC and implemented as a custom PCB in KiCad.

The circuit generates an audible sound through a buzzer when two contact points are connected. The project was created to learn the complete PCB design workflow including schematic capture, PCB layout design, routing, design rule checking, and Gerber file generation.

## Components Used

- NE555 Timer IC
- Buzzer
- Battery
- 2 Resistors
- 2 Capacitors

## Working Principle

The NE555 Timer is configured in an astable mode to generate a square wave output.

When the contact terminals are connected, the circuit is activated and the buzzer produces an audible tone. The resistors and capacitors determine the oscillation frequency of the timer.

## Design Tools
